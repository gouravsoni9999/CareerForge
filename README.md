# CareerForge

CareerForge is a full-stack internship and placement management platform
designed to connect students, recruiters, and placement administrators.
Technology Stack
- Frontend: React, TypeScript, Vite
- Backend: Django, Django REST Framework
- Database: PostgreSQL
- Containers: Docker, Docker Compose
- Cloud: AWS
- Automation: GitHub Actions (planned)
Core Features
- Student profiles and academic information
- Internship and placement listings
- Eligibility validation
- Application tracking
- Recruiter shortlisting and interview scheduling
- Placement administration and analytics
Project Structure
- frontend/ — React frontend
- backend/ — Django REST API
- docker/ — Docker-related configuration
- docs/ — Architecture and API documentation

Development Status
Milestone 1: Project foundation and local environment setup.
Security
Never commit .env files, passwords, API keys, or cloud credentials.
Use .env.example to document required environment variables.
